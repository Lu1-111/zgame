# ITM-B01 材料与特殊道具 RAW v001

内置 `image_gen` 生图，保存 5 张原始透明 PNG / 20 个待机候选帧：奶菇、蜜蜡、奶晶、背包扩容卷、地图碎片。每项配套完整 `.prompt.txt` 与 `.layout.json`；汇总见 `batch.json`。

各张采用 2×2 阅读顺序（左上、右上、左下、右下）。设计为同一固定道具仅表面高光变化的四帧循环。圆润奶系幻想像素、深紫褐轮廓、奶油主色与局部糖果色；已参考 CHR-01 主造型。卷轴和地图无文字。透明区保留生成器原始 Alpha，未去底、绘制或重采样。

提示词请求 1024×1024，生成服务实际均返回 **1254×1254 RGBA**，单格 **627×627**。不得把请求尺寸误写为实际尺寸。名义源锚点均为每格 `(313.5,470.25)`；这是规格锚点，不代表生成器严格遵守主体位置。`layout` 逐格记录 alpha 1 / 16 / 128 / 240 的可见边界，供统一 PROCESSED 阶段校准。

奶菇与奶晶主体位置很稳定；蜜蜡右列约左移 25 源像素、下排约上移 36 源像素，必须按可见主体统一中心和底部，才能避免播放抖动。背包卷与地图也需做统一注册与成品尺寸检查。只做 RAW 测量，不先行制作 PROCESSED。

建议成品世界掉落帧 32×32、root `(16,24)`、6 fps 循环，UI 图标 24×24。最终播放规格与角色/掉落组件由主代理统一确定。原图路径及 SHA-256 均已记录；5 张项目副本与生成源逐字节一致。

本目录未修改场景、游戏脚本、数值表或主素材清单。素材是否进入游戏由后续集成步骤决定。
