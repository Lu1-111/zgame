# ITM-B01 v001：碎片与能力奖励 RAW

本组使用内置 `image_gen.imagegen` 分别生成 4 张真正 RGBA 透明的 2×2 待机循环图，共 16 帧。原始输出按字节复制保留，未抠图、裁切、重绘或缩放。提示词和每张的来源路径、SHA-256、实际布局与测量记录位于同名 `.prompt.txt` 和 `.layout.json`。

| 数据 ID | 视觉 | 计数 |
|---|---|---|
| `hp_fragment` | 红珊瑚心形晶片，奶油白心核 | 正式道具 |
| `sta_fragment` | 翡翠绿非对称尖叶晶片，奶油内核与叶脉 | 正式道具 |
| `mana_fragment` | 青蓝水滴晶片，奶油内核 | 正式道具；由消耗品子代理补生 |
| `ability_double_jump` | 奶白悬浮水滴，下方两层青蓝奶泡弧环 | OBJ-06 / ABL-01 附加能力奖励，不占正式 12 道具 |

## 原稿规格

- 请求为 1024×1024，内置工具实际全部返回 1254×1254；每格为 627×627，行优先 `[0,1,2,3]`。
- 每格名义源根锚点统一记录为 `(313.5,470.25)`，即单格宽度的 1/2、单格高度的 3/4。
- 所有图具备真实 Alpha，但存在大量半透明边缘与少量低 Alpha 背景像素；不能用 `alpha > 0` 的全图包围盒定位主体。
- RAW 仅作为设计源稿，尚未通过游戏直接导入验收。此目录没有创建 PROCESSED 或修改工程接入。

## 连续性与 processed 处理要求

道具轮廓、朝向与主体大小保持接近；变化以表面闪光、小闪点为主。生成器仍产生了布局偏移，必须在 processed 阶段按实测主体中心和底端做单帧对齐，不能直接按等格切片后播放。

生命碎片的格内主体底端依次为 557、557、509、509，主体水平中心约 338、289.5、337、290.5。体力碎片的底端依次为 559、559、539、539，水平中心约 367.5、309、367.5、309；下排尖叶顶端距格边仅 49 像素，未满足提示词所要求的 64 像素安全边。奶力碎片主体底端约 563–564，水平中心约 313–314。上述原稿偏移与安全边偏差均应在成品登记中处理。

能力奖励主体水滴中心和底端基本稳定；其两层奶泡弧环由多个不连接的组件构成。对齐或裁切时须把两层弧环与水滴作为完整奖励组保留，不能只保留最大连通组件。相邻帧高光存在少量轮廓内细节变化，成品需检查 4→1 衔接。

总批次索引为 `batch.json`。每张原图 SHA-256 可与 `generatorPath` 原始输出复核。处理后的统一画布、最终锚点、播放速度和验收结果由总批次 PROCESSED 流程记录。
