## 造型基准

`CHR-01_master_right_v001.png` 是本批统一参考：黄色身体、奶油色肚皮、绿色眼圈、深色手脚，面朝右，像素画表现。后续动作均引用这张基准图。原始原型未修改。

每张图片旁的 `.prompt.txt` 保存实际生成提示词；`.layout.json` 描述动作、播放顺序和原图位置。`RAW` 保留生图原尺寸及透明度，不将它们伪装为已经严格对齐的精灵表。修订图保留独立版本文件；实际采用哪一版以 `PROCESSED` 的 `manifest.json` 为准。

## RAW 与 PROCESSED 的边界

- 生图结果的行距不一定相等，不能直接按画面等分切格。
- 角色、武器、动作造型均由 image_gen 生成；机械处理负责切帧、等比例缩放、透明画布排布与资源打包。
- 成品默认使用 64×64 画布、右向、根锚点 `(32,58)`；大幅武器动作使用 96×96、根锚点 `(48,90)`。两者的身体像素尺度与世界坐标中的接地点相同。每张来源图使用一个统一尺度，避免逐帧按外包围框拉伸导致体型忽大忽小。
- 站立、腾空和倒地分别标定接地或身体根点；空中动作不强制把脚贴到地面，死亡动作不强制恢复站立高度。
- 成品坐标、帧序、来源版本和播放速度以 `PROCESSED` 中的清单为准。原始动作画含逐帧造型变化；本批不包含骨骼绑定、补间动画或左向武器专属动作。

坐下、休息和起身采用同一张 `rest_cycle v002`，旧 `rest_transition v001` 作为过程版本保留。起身最后复用已有站姿，待机/落地/闪避也可复用已有过渡帧；这些播放引用不计为新生成图片。

武器组采用 `combat_A v002`（修复锤头边界）与 `combat_B v001`。枪口释放提示随角色保留，源图能量束尾端触边，不能把它当作完整的独立弹体特效。
