# FX-B01 原始特效批次

依据项目《素材设计清单》§5.1、§5.2、§5.4，为现有 CHR-01 玩家动作补充独立特效。

- `impact/`：FX-01 物理命中、法术命中、普通格挡、完美格挡、破防。
- `motion/`：FX-02 落地尘、起跳尘、闪避残影；ABL-01 二段跳奶泡。
- `hammer/`：WPN-01 奶瓶锤横扫、上挑、重砸。

全部原稿通过内置 `image_gen` 生成；每个效果使用独立调用。实际提示词位于各 PNG 同名 `.prompt.txt`，入选源图和生成路径见各组 `batch.json`。修订保留旧版，不覆盖原图。`.qa.png` 是检查合成图，不是透明源素材。

每张入选原稿预期为 1536×1024、3 列 × 2 行、6 个连续时序帧。原图保留完整 RGBA。RAW 中存在不表示已经通过成品验收；只有统一裁格、缩放、语义锚点校准、透明及连播检查后的文件才进入 PROCESSED。

处理保持每个效果统一缩放比例，不使用逐帧包围框归一化；命中类以碰撞接触点为 root，运动类以脚底 root 为基准，挥击类以挥击轴心为基准，重砸以地面落点为基准。源图上下排的实际基线偏差由显式 sourceAnchors 记录，整数平移后目标 root 保持一致。

生成图查看器可能展示 alpha 为零处保留的 RGB。检查柔光与背景时须将 RGBA 实际合成到暗底或明底；不能把透明区域的 RGB 直接当作可见背景。低 alpha 像素原样保留，不以去背景或阈值裁切掩盖问题。
