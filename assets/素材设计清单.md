## 1. 本次准备范围

按参考书 v1.1 准备 **奶泉营地、奶源林地、蜜乳洞窟，共 15 个房间**所需的视觉素材：玩家、NPC、8 种小怪、3 种精英、1 个 BOSS、4 种武器、5 个技能、12 个天赋节点、道具、场景、交互物和界面。

参考书 §1.4、§2.4、§3.13 的本期开发仍采用灰盒。本清单用于提前设计、试生成和积累正式美术资源，不把整套正式美术变为灰盒版本的前置条件。

**来源与建议的区分：**角色名称、数量、动作机制、区域及界面布局来自参考书；本文补充的画布尺寸、动画帧数、配色倾向和生成批次均为制作建议，首批样张验证后再固定。文中的 ID 是本清单的追踪编号，不是现有游戏数据 ID。

本次不纳入：③崩塌奶厂、④星乳高塔、⑤银河要塞、后续 BOSS、后续五项能力及完整商业宣传物料。三重奶泡只预留天赋图标，不扩展成新的能力动画包。

### 3.2 首批样张采用的建议

- **风格：**圆润、辨识度高的奶系幻想像素美术；背景压低对比，角色、交互物和攻击预警更醒目。森林偏苔绿，洞窟偏蓝紫，蜂巢以蜜金作局部强调。
- **视角：**横版侧视，角色可站在同一条地面基线上。设定展示图可以有多个视角，但游戏动作帧使用统一侧视。
- **角色画布：**本批玩家常规动作采用 64×64；大范围武器动作采用 96×96 透明留白，身体尺度不变。其他角色的建议为：普通敌人按体型选择 48×48 或 64×64；精英 96×96；女王先以 160×160 验证。攻击超出画布时增加独立效果层，不挤小主体。
- **图标建议：**物品、武器、技能、天赋先统一试制 24×24 成品图标，适配 26/28 像素槽位；可另留高分辨率设计稿。缩小后必须检查可读性。
- **背景建议：**按 640×360 可视区设计远景、中景和前景；宽房间通过延展或拼接覆盖，不能直接拉伸一张图。角色层与背景层分别制作。
- **透明要求：**角色、武器、可拾取物、图标、独立特效使用真正带 Alpha 的 PNG；背景的最远层可不透明。透明棋盘格不能画进图片里。
- **像素一致性：**概念稿可较大；正式素材以约定像素尺寸逐项检查轮廓、颜色和边缘，不能仅把大图缩小就标记为完成。
- **文字与界面：**按钮文字、数值、物品描述和中文标题由界面排版；生图只准备无字皮肤、装饰、图案和图标。

```text
素材 ID / 名称：
用途 / 所属房间或界面：
依据：参考书章节 + 本清单条目
参考图：已选定的 RAW 文件路径（若有）
视觉：角色身份、比例、材质、配色、光向
```

## 10. 从 RAW 到 PROCESSED 的验收

- [ ] 文件可打开，名称与清单 ID 对应，保留原始版本。
- [ ] 造型、色板、光向、轮廓粗细与已选定的参考图一致。
- [ ] PNG 透明度正确；没有白边、假透明棋盘格、文字、水印或多余主体。
