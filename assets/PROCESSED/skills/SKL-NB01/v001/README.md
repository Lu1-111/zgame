# SKL-NB01 · 六技能候选素材包

已整理 **96 帧 / 24 组动画 / 6 枚技能图标**，对应制作人最新的“新奶流-拔刀、奶龙大笑、王从天降、奶之毅力、虚式-奶、奶法之源”。美术由内置 image_gen 生成，原图和实际提示词保存在 `assets/RAW/skills/SKL-NB01/v001/`。

双击 `preview.html` 可离线查看全部动作与特效，支持暂停、明暗底和锚点。Godot 资源入口为 `godot/SKL-NB01_sprite_frames.tres`。

- `frames/`：96 张逐帧 RGBA。
- `sheets/`：24 条四帧精灵条。
- `icons/`：6 张 24×24 图标及各自 96×96 检查图。
- `review/`：六组原稿在明 / 暗底的检查图与动态预览截图。
- `manifest.json`：帧序、原图、SHA-256、来源矩形、源 root、目标锚点、Godot offset、播放建议。
- `processing_config.json`：可重建的美术处理参数；`qa.json`：透明与裁格检查结果。
- `validation.txt`：最终导入、资源加载和单元测试输出摘要。

角色采用 96×96、脚底锚点 (48,84)，站高约40px。每张来源图统一身体尺度；抬脚和腾空保持姿态，游戏世界位移由后续玩法驱动。SpriteFrames 自身不设置节点偏移，使用时按每动画的 `godot_offset` 设置 AnimatedSprite2D.offset；不应直接用旧主角资源的锚点假设覆盖这些值。

状态光效默认贴角色身体中心；拍地法阵与碎石冲击贴地面；眩晕星环贴敌人头顶；光球及爆炸使用独立实体中心。使用最近邻取样，左右镜像以 source root 为轴，瞄准光球可随方向旋转。收尾的稀疏粒子需要随状态或实体回收隐藏，不能在最后一帧永久停留。

这些是可供接入和手感联调的候选视觉资源。没有增加战斗逻辑、音效、技能装备界面或剑类武器；不覆盖当前 CHR-01，也不改旧五技能。大笑循环有姿态幅度变化，光球循环有体积脉动，需在玩法里结合实际镜头和命中区域继续评估；不能用图片外轮廓直接生成伤害碰撞。

设计表 `data/skill_designs/SKL-NB01.json` 中的空值是未定规则，不能当零值使用。尤其注意互斥规则、击杀回复基准、伤害倍率、光球速度和地形/BOSS控制规则待制作人后续定案。
