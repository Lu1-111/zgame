# ENV-02 奶源林地 · ENV-B01 v001

本套件由内置 `image_gen` 生成三张原画，再进行机械裁切、最近邻缩放、色板约束与接缝校准。原画保存在对应 RAW 目录，未覆盖或改写。完整生成提示词见 RAW 的 `prompts.json`，原图 SHA-256、尺寸与处理步骤见 `sources.json` 和本目录 `kit.json`。

## 可用文件

| 文件 | 实际规格 | 用途 |
|---|---|---|
| `terrain.png` | 64×64 RGBA；4列4行；每格16×16 | 连续行优先索引的林地地形 |
| `background.png` | 640×360 RGBA，不透明 | 低对比森林远景，基调 #16241a |
| `background_vertical.png` | 640×720 RGBA，不透明 | forest_03 竖房；原画等比窄裁切加根部模块，无纵向拉伸 |
| `midground.png` | 640×360 RGBA，真透明 | 上缘树冠、边缘藤蔓，中间通路留白 |
| `props/*.png` | 9件；画布均为16倍数；alpha仅0/255 | 巨木、树冠、树根、藤蔓、断桥左右端、苔石、洞口、蕨菇 |
| `atlas_preview.png` | 320×192 | 实心3×3语义体、横向重复、薄平台、内角候选 |
| `props_preview.png` | 768×528 | 九模块总览，预览文字不进入游戏素材 |

`terrain_layout` 的0～8是连续行优先索引，依次为 TL、T、TR、L、C、R、BL、B、BR；并非在64×64图集左上方放一个3×3矩形。9=single，10=thin_left，11=thin_mid，12=thin_right，13=inner_left，14=inner_right，15=transition。完整映射以 `kit.json` 为准。

## 锚点与层级

普通物件的 `anchor` 为底部居中；藤蔓为顶部居中。断桥另有 `surface_anchor`：左端 `[96,65]`，右端 `[88,57]`。桥梁中央木板顶面按此点对齐现有平台表面，不按画布底部对齐。木板原画有约2像素起伏，桥梁本身不创建碰撞。

背景放 `z_index=-30`，中景为 `-10`，地形为0，独立装饰不超过1，角色和敌人为20。桥梁优先放中景并对齐已有平台；装饰不能让缺少碰撞的区域看起来可站。不要直接横向拉伸一张背景覆盖宽房；采用相邻镜像段或独立模块拼接。

## 检查结果

15张PROCESSED PNG均已逐张查看，九模块另做总览；桥梁已放大核对中央顶面。透明素材采用二值alpha，透明像素RGB归零，无烘焙棋盘格。背景全部alpha=255。地形21组横向/纵向重复与相邻边缘逐像素比较，全部不一致像素数为0。详细机器结果见 `qa.json`。

地形底图纹理来自原画，内角13/14供地图拼装选择；没有修改地图布局、碰撞、门条件或角色数值。forest_03 的二段跳语义门条件是否等价于物理不可绕过，应由玩法测试另验，本美术批次不改变该逻辑。

本目录只提供ENV-02套件；15房完整地图由本批次统一地图合成器输出，避免各美术套件分别改动世界数据。
