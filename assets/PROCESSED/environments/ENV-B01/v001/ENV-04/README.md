# ENV-04 蜂巢分区 — ENV-B01 v001

本套件来自内置 image_gen 的两张原始图像。RAW 保留原图、完整提示词与 SHA-256；PROCESSED 是用于地图搭建的派生资源，尚未改写当前运行房间或碰撞数据。

## 文件

- `terrain.png`：64×64 RGBA，4×4 图集，每格 16×16；Nearest 采样，不加纹理过滤。
- `background.png`：640×360 RGB 不透明背景，底色为洞窟 #120f1c，压低饱和度与对比。按单屏延展使用，不横向拉伸成长房。
- `background_wide.png`：1280×360 RGB 女王大厅专用宽幅背景。来自单独新生成的宽幅 RAW；从 2172×724 原图裁出 2048×576，统一缩放 0.625。两翼框景只在左右边缘，中间 60% 连续留白；长房优先使用此文件，不镜像拼接 640 背景。
- `props/*.png`：4 个带真正二值 Alpha 的可复用装饰，画布为 16 的倍数。
- `kit.json`：文件、尺寸、锚点、图块语义与原始来源。
- `atlas_preview.png`：实心区域、薄平台、内角与重复填充的实测拼接图，原生像素放大 2 倍。
- `contact_sheet.png`：背景、图块和道具总览。
- `qa.json`：尺寸、模式、Alpha、18 组接缝和文件哈希的实际检查结果。
- `design_notes.md`：箱庭构图与摆放建议。

## 图块顺序

连续 row-major 索引：0 TL；1 T；2 TR；3 L；4 C；5 R；6 BL；7 B；8 BR；9 single；10 thin_left；11 thin_mid；12 thin_right；13 inner_left；14 inner_right；15 transition。0–8 是实心地形九宫格；10–12 的有效高度为 8 像素，余下透明。

## 处理与检查

原画为高分辨率像素风格设计稿，并非直接宣称为原生 16px 成品。处理先按记录坐标裁切，再用 Nearest 归一化；九宫格只复制原画已有纹理/边条进行接缝校准，未生成程序噪声替代美术。单张源图和处理坐标可追溯至 `work/env_b01/cave/process.py`。

原图与派生图均已打开检查；背景中央不放可站立结构，地形边缘连续，道具 Alpha 透明。18 组主要地形连接逐像素相同。内角与过渡块作为独立候选使用，未宣称具备任意方向自动地形完备性。

悬挂类道具 honey_cells 的锚点为上中，其余为下中。背景建议 z_index -30~-10、地形 0、装饰 1，角色与敌人 20。
