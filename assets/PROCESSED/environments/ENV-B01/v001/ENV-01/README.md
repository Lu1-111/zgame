# ENV-01 奶泉营地 · ENV-B01 v001

本套件为 15 房地图制作提供营地与商人之家的可复用图像。原画全部由内置 `image_gen.imagegen` 生成；没有用程序替代原画。RAW 保留未改动的生成 PNG，完整 prompt 见对应 RAW 目录的 `prompts.json`，来源校验见 `sources.json`。

## 交付

- `terrain.png`：64×64 RGBA，4×4 图集，单格16×16。行优先索引语义为 TL / T / TR / L / C / R / BL / B / BR / single / thin_left / thin_mid / thin_right / inner_left / inner_right / transition。
- `background.png`：640×360，不透明营地远景，低对比，底色基于 `#1a1614`。宽房间以单屏重复或镜像拼接覆盖；禁止拉伸至整个房间宽。
- `interior_background.png`：640×360，不透明商人之家空室内背景，右侧门口可作为返回营地的方向提示。
- `props/`：9 件透明模块，尺寸、底部中心锚点和来源裁切框见 `kit.json`。木屋144×112；帐篷128×80；奶泉128×80；货架96×80；篝火48×48；储物箱64×48；回营门96×96；木箱路标96×80；回营落点旋纹32×32。
- `atlas_preview.png`：实心3×3、长地形块和薄平台的1倍拼接展示。
- `qa.json`：实际尺寸、alpha、18项地形接缝及背景重复边缘结果。

## 地图构图建议

奶泉作为 `camp_01` 主地标，让玩家从森林返回时可以立刻认出安全区。将篝火与仓库组成一个功能簇，商人之家木屋形成另一个入口簇，中间保留行走空白和视线；装饰成簇，不均匀铺满所有平台。

`return_glyph` 放在 `camp_01` 顶部返回平台上方，以锚点(980,40)对齐，形成回营时可记住的奶蓝旋纹。它从既有 `return_arch` 内(33,34)-(63,90)机械裁切，提取奶蓝连通分量及已有高光，Nearest等比缩至15×28内容并放在32×32画布底部居中；锚点[16,32]。没有新增RAW或创意重绘，源哈希、裁片与缩放记录见 `kit.json`。完整门框仅留作有足够高度的场景备用，禁止在顶部空间不足时clamp产生梁穿门框。

`camp_02` 用空室内背景配独立货架与箱子。原画不含文字，路标信息应由游戏界面排字。建筑和装饰建议 `z_index=1`，背景按工程约定置于负层，角色与敌人保持20。

## 处理与审查

1. 原图逐张保存，记录SHA-256；地形原画网格不是直接运行图集。
2. 从原画裁取连续土纹、草皮和木梁，Nearest 缩放到16px，并复用相邻像素闭合拼接边。土层浅色石粒压低对比后再次视检。
3. 背景等比缩放并中心裁切到640×360，压低对比并归入32色色板；远景末端暗树像素校准，左右边缘可闭合。
4. 构件按真实alpha包围盒裁切，等比Nearest缩小，32色量化，放入16倍数画布，alpha以160阈值归整为0/255；保留底部基线。
5. 已实际查看原画与处理后的地形拼接、背景、室内和全部模块。18项地形边缘像素精确匹配；9件props均为真实透明，无棋盘格。回营旋纹另检验所有可见像素均保留源色。

## 使用边界

这是16格基础手工地形集，尚不是Godot47格自动地形图。薄木平台厚6px，画布底部透明；碰撞和单向穿越由房间设计定义。内角是基础2px凹角，复杂轮廓需后续扩展。

营地互动道具仅为静态地图视觉，不含篝火循环、储物箱开合或门状态动画；NPC和角色沿用已有独立素材。室内背景的地板为远景视觉，实际站立面仍由地形与碰撞决定。本轮没有修改场景、脚本、数据或主清单。
