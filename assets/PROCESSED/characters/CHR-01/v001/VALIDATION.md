# CHR-01 v001 验证记录

日期：2026-10-24。正式资源目录为本文件所在目录。用户原型及全部生成原图保留在对应 RAW 目录；本次只做机械裁格、Nearest 等比例缩放、整数平移和排布。

## 数量与规格

- 26 个动作，112 张独立动作 PNG，118 个播放引用；复用的过渡帧没有重复导出计数。
- 88 张 64×64、24 张 96×96。扩展画布用于三段锤击、枪蓄力、奶杖和法球动作，保持身体尺度。
- 另有 1 张 64×64 主造型、26 张动作条、1 张 atlas、1 张总览。
- 普通 root (32,58)，扩展 root (48,90)，两者指向相同世界原点。主造型可见站高 40px；动作站姿因像素栅格为约 40–41px。

## 自动独立检查

`validation.json` 保存结果；以下检查全部通过：

- 每张动作 PNG 的真实 Alpha、画布尺寸和透明边距；没有非透明像素贴住成品画布边缘。
- 112 张动作 PNG 与 atlas 对应区域逐像素 RGBA 完全一致，最大通道误差 0。
- 9 张入选动作源表的 SHA-256 与 manifest 来源一致。
- 118 个播放引用均可解析，独立文件计数为 112。
- 接地校准的动作以 alpha≥128 检查，脚底可见像素至 y=57，接触线 y=58；纯整数校准量写在 `pixelOffset` / `contactCorrectionPx`。
- 源裁边和成品越界警告均为 0。

## 播放与引擎检查

使用 Playwright + 系统 Chrome，通过只暴露本目录的 127.0.0.1 临时服务实际打开预览。26 个动作选项、切换、暂停、逐帧、速度、持续播放和碰撞框叠加均通过；页面无 JavaScript 错误。服务随后关闭。预览仍为自包含 HTML，可离线使用。

实际使用 **Godot 4.7.2.stable.official.ed1daf0bf**，在独立验证目录进行无头导入及场景实例化；结果为 **26 动画、112 唯一 AtlasTexture、118 播放引用**。64/96 动作切换时 offset 在 (-32,-58) / (-48,-90) 间正确更新，世界 root 保持不变。没有声称使用参考书中的 Godot 4.4 执行验证。

## 逐帧视觉复核

运动与战斗代理分别复核了各自的成品帧、根点和基线；打包代理复核裁格、源边界及输出。待机、落地、地面闪避接地稳定；跑步第 4、8 原画帧保留 2px 腾空，不强制贴地。空中姿态保留虚拟地面。武器较大时扩整组画布，不挤小人物。

休息的进入、循环和退出使用同一源表；退出末尾复用 `rest_enter_1`、`rest_enter_0`，6 步 / 12 FPS，共 0.5 秒。起身仍存在少量原画姿态差，属于逐帧动画，未宣称骨骼级无缝。

## 使用边界

本批是素材与资源导入交付，未修改游戏状态机或完成实机手感测试。武器及少量动作示意效果现阶段合层；枪蓄力释放的光束尾部在 RAW 源图触边，不作为完整独立 FX 资源。左右持握、伤害范围、无敌时间和技能效果仍由接入阶段确认。
