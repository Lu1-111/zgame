# CHR-01 奶龙角色素材 · v001

本批共 **26 个动作、112 张独立动作 PNG、118 个播放步**，另有 1 张主造型。素材均由对应 RAW 原图确定性分格、等比例缩放和整数平移整理，未使用程序绘制角色或生成补间。

- 打开 [preview.html](preview.html) 可离线播放、暂停、逐帧、调速和叠加 root / 碰撞框。默认待机；所有动作按相同 4× 倍率显示。
- [contact_sheet.png](contact_sheet.png) 是全部独立原画的总览；重复的播放引用不作为新原画。
- [manifest.json](manifest.json) 记录 RAW 来源、SHA-256、裁切矩形、每张源表固定比例、root、整数校准量、atlas 区域与播放顺序。
- `frames/` 是独立透明帧，`sheets/` 是每动作的原画条，`CHR-01_atlas_right_v001.png` 是规则 atlas。
- `godot/CHR-01_preview.tscn` 与 `CHR-01_sprite_frames.tres` 可整体复制进 Godot 4 工程。根点同步脚本会在动画切换时更新画布 offset。

## 统一规格

画布：64×64：88 张；96×96：24 张。普通帧 root 为 **(32,58)**；扩展武器帧为 **(48,90)**。两者都指向同一个世界地面原点，身体站高约 40px。武器/效果伸出时扩展整组画布，不缩小人物。Nearest、真 Alpha、无 trim/rotate。

每个 RAW sheet 只校准一次缩放比例，所有帧共享；不根据逐帧包围框改变大小。接地动作的 alpha≥128 可见底边对齐接触线，`transform.contactCorrectionPx` 记录该整数位移。运动帧的明确修正放在 `pixelOffset`；腾空帧保留虚拟地面与离地高度。

待机、落地、闪避复用已有中间帧作回程；`sourceFrameIds` 为独立原画顺序，`playbackOrder` / `frameIds` 为播放引用。没有把重复引用算成新增美术。

## 接入说明

角色图与武器、少量动作示意 FX 目前合层；枪口/弧线/法球不作为独立完整 FX 资源。碰撞体 20×34 和受击框 24×38 是参考书的游戏逻辑规格，不从精灵透明包围框推导。攻击判定、无敌时间、跳跃轨迹和 1.5 秒死亡流程由状态机控制。

本批全部面向右；左右镜像是否符合持握关系需在游戏接入时检查。此批完成素材准备和资源导入验证，尚未修改游戏状态机或完成实机手感验收。
