# 原生手臂、胸前持握格挡

四种武器各3张完整96×96 PNG，脚底锚点48,84。身体直接取自现有 hammer_1 的完整动作帧，保留原肩、肘、前臂、手掌、人物形象与原生像素密度。不会擦掉原手臂后另画线条。

- 三阶段：准备、前送举起、胸前就位；四类共用同一身体动作。
- 武器沿用对应攻击武器：剑枪原绘制；锤杖原攻击像素，握柄参照原攻击中可见的同款柄补全。
- 只让原手掌接触握柄的部位处于武器前方；不把胸腹或整条手臂覆盖到握柄、枪身上。
- 维持时手臂留在胸前，横竖不作硬性限制，按合理持握确定角度；不举过头顶。
- bodies/ 和 weapons/ 保存原身体、完整武器图层，data/guard_frames.json 保存全部来源、原像素色板、握点、遮挡范围和校验值。

生成：godot --path . --script res://tools/assets/build_guard_frames.gd，然后 headless import。需要图形渲染，建议使用隐藏窗口、低帧率及进程看护。运行时只播放最终完整PNG。
