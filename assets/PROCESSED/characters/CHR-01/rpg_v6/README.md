# 正式身体与原生手臂联动

替换 v5 的闲置身体加程序手臂。运行时使用既有 v001 锤、杖、射击完整动作及原手掌像素；原图不修改，人物密度不缩放。剑击头肩、躯干和下肢一同换帧；步枪使用正式射击后坐，俯仰时上身与原手臂联动，脚部保留地面支撑。

本目录 64 张 96×96 PNG 为导出检查帧：三段剑各八帧，五个枪械方向各八帧。原人物仍为原生密度，96 画布仅为武器和动作保留透明边距。运行时由 `scripts/player/pixel_hero_rig.gd` 根据 `data/hero_motion.json` 实时选择原姿态，瞄准支持连续角度。

`tools/preview_hero_rig.gd` 可重新导出。慢放与逐帧说明见 `docs/角色动作联动修正-2026-10-27.md`。
