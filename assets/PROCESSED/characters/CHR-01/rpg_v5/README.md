# 原像素角色的双手直剑与步枪

64 张 96×96 PNG：三段剑各 8 帧，五个方向的步枪各 8 帧。仅画布增加武器留白，正式闲置母版保持 1:1。没有新增背鳍或重画人物头身。

运行时使用 `scripts/player/pixel_hero_rig.gd`；对原手臂区域作局部替换，按原图取色绘制两条手臂，两手、剑柄或枪身共用握点，禁止叠加第三只手。剑有整体重心变化、长握柄与三种挥法；步枪按连续角度瞄准，PNG 的五方向仅供检查。参数见 `data/hero_motion.json`。

使用 Godot 正常渲染器运行 `tools/preview_hero_rig.gd` 可重新导出。导出时使用 `--max-fps 15`，辅助进程完成后自行退出。对照图为 `docs/previews/hero_sword_rifle_v5.png`；最后一行展示正式格挡素材的举手、保持与放下顺序。
