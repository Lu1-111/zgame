# corrumpt · 本体与特效统一材质 v005

2026-11-02 当前正式版本。已确认的v004本体八帧和二阶段花体八帧原样复制；角色42px、Boss84px、固定根座、心跳播放进度与伤害倍率保持一致。最新战斗行为与生命参数以`data/bosses/claffert.json`及`docs/gameplay/corrumpt第一阶段.md`为准。

## 修正原因

v004触手的源图材质过于平整，且长宽分别归一造成宽色带，与花苞的细密像素纹理不一致；圆环运行时整体缩放又会让纹素随半径变大。此次以花苞母版为唯一材质参考，内置imagegen重新绘制触手与全部效果。原始图和完整提示词保存在`sources/`及`PROMPTS.md`。

- 触手：细紫色纤维、橄榄色根茎与黑色裂纹，阴影和高光与花苞同源。原图根端逐帧标定，只按伸展长度等比采样，保留纹理比例与棘刺轮廓；不再分别拉长、压扁两个轴。
- 固定触手画布352×320、锚点(48,288)，世界连接点(±20,-4)不变。水平伸展238px约3.5个本体宽，最高举起160px。最终高举帧另绘宽弧形触手并离线旋转对齐，按238px伸展等比采样后仍为160px高；没有压扁材质。砸击仍停顿0.2s、六帧挥落0.5s，整次动作按触手实体轮廓判伤，落地冲击仅作表现。
- 地刺32×40：选用同源藤刺的中心尖刺束，保留入地/出地/收回帧，固定地面基线。
- 针弹40×16、孢子20×20：以主要实体轮廓对齐，排除散落粒子导致的包围盒漂移，不按每帧动态缩放。飞针放大通过高分辨率源图重新采样，保持1世界单位纹素。
- 砸地冲击236×32：使用同色根须碎片和细冲击丝，低矮横向展开，保留四个消散阶段。
- 引力/震退环：96×12原生环带逐帧纹理。`pixel_ring.gdshader`在1世界单位网格上沿周长采样，仅改变半径，纹素与环带宽度全程不变；不再放大整张圆环图片。
- 所有素材共用本体32色色板与硬透明、nearest显示。本体不镜像、不变形、不随招式重置帧；没有骨骼动画。

双触手显示修复：只读识别根端所属的连通块，裁图范围保留到整行末端，既排除相邻格碎像素，也避免裁掉长触手末梢。待机四帧共用同一根端母版，长度48/49/48/47px；左右始终存在，地下阶段也保留地表根端。自动检查每张待机图在本体之外至少露出16个像素，防止再次缩没。
