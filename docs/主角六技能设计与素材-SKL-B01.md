# 主角六技能设计与素材 · SKL-B01

日期：2026-10-26。状态：设计提案与素材准备，尚未接入玩法。参数记录于 `assets/PROCESSED/skills/SKL-B01/v001/skills.design.json`；工作源为 `work/skill_b01/design/skills.design.json`。

本轮保留制作人指定的「超究极武神霸斩」「极巨化奶光炮（蓄力释放）」，补充突进、控场、防御反击、治疗四种用途。六招供技能库选择，沿用四个技能槽 Q/E/R/F，不增加键位；E 键与交互的既有冲突仍待决策。

六招均地面施放，保持现有体型、碰撞体、角色脚底锚点。极巨化只让能量变巨；不让身体变巨，也不增加跳跃、空中悬停、能力门越界。

## 动作与判定分离

全部原画朝右。每招目标8张角色关键帧；关键帧是阶段样本，逻辑出手时刻读JSON，可通过保持帧、循环帧或持续时间适配，不能把「第几张PNG」写死成伤害事件。所有角色应与现有 CHR-01 素材同一比例、同一脚底注册点，左右方向由运行时镜像。

角色和特效分层：角色保持统一锚点，刀光、炮口、光束、地面星环、盾、奶泉单独导出透明PNG。光束需要炮口、可平铺中段和头端，以便按最近墙体裁短；不要在角色帧中烘焙一整根固定长度光束。彗星冲的移动由物理控制器完成，图片里的身体保持注册点，拖尾可以向左延伸。

奶光炮采用「聚能后张口发射」：双手只做聚能与架势，光束从嘴部发出。默认炮口位于脚底锚点相对坐标 `[14,-30]`，成品每帧语义嘴点允许1至2逻辑像素偏移，并须记录到逐帧元数据。必须提供起手、聚能增长、蓄满循环、释放、收招五个可分辨阶段。按下时检查至少可付最低档，释放时按已达到且当前可付的最高档扣奶力、开始CD；蓄力闪避取消与受击中断均不扣费。释放后同一目标最多一次伤害，持续光束外观不等于重复伤害。

霸斩明确五次短斩加一次终结斩，保持身体连续旋转与收势；它没有全程无敌、瞬移或自动追怪，BOSS可离开范围。所有收招可以被现有闪避取消。已提交技能取消后不退奶力与CD。

## 控场、护盾与边界

星环对普通敌人定身1s，再减速40%持续1s；精英不定身、减速30%持续1s；BOSS不定身、减速15%持续0.6s，不能打断攻击或换阶段。法术免疫敌人不吃该法术控制，圈不是实体墙，不能把敌人夹入地形。

镜返正面举盾最多3s，总吸收32，完美窗口从护盾实际展开起算0.18s。普通攻击超过吸收池的部分照常扣血；反弹沿用参考书30%规则，不复制同一弹体反弹伤害。BOSS不吃强制硬直。旧奶盾与镜返后续应互斥，不能叠双吸收池。

奶泉每秒最多恢复8%最大HP，共4次，离开时不补发；只能治疗同房间、同地面且无遮挡的玩家。泉不是可站立平台，不能垫高跳跃。切房/死亡清除。

全部近战、光束、控制与治疗范围检查世界遮挡。彗星冲碰墙停止；不穿能力门，不改碰撞层。各技能伤害类型独立于当前武器类型，基底攻击沿用参考书公式，仍走抗性、防御和暴击；普通武器回奶词条不因技能多段触发，技能命中回奶天赋每次施放最多触发一次。

## 与旧五技能的关系

参考书§3.6和当前 `data/skills.json` 是五招。制作人本轮明确要求设计六招，因此本轮设计与素材数量按六招执行。此交付未修改参考书、live表、天赋、宝箱、商店、存档或游戏脚本。旧五招仍运行原行为，新六招是待接入方案。

旧奶泡弹保留低耗快速远程位，奶光炮提供蓄力高耗输出；旧挤奶冲击是原地近战法术，彗星冲是地面物理位移；旧奶盾是全向吸收增益，镜返是主动正面读招；旧治愈之乳是即时治疗，奶泉是地面持续治疗；旧星乳坠落是法术范围爆发，霸斩是贴身物理终结。后续接入应由独占数据表的代理迁移技能库与四槽装备，不直接把旧ID替换成新ID，避免破坏已解锁状态与存档。

## 后续玩法验收要点

1. 奶力不足不释放；蓄力取消不扣费；三档释放按实付档开始CD。
2. 六次霸斩判定可重复打中同一目标，但每个事件对该目标只结算一次；光束与突进每目标每次施放只一次。
3. 法术免疫与BOSS抗性照常生效；BOSS不定身、不强制硬直、不被推入墙。
4. 每个收招都能闪避取消；其他取消规则按JSON执行。
5. 任何技能不穿墙、穿门或替代二段跳能力门；动画保持原脚底锚点。
6. 技能图标在26×26显示时仍能区分刀光、光束、彗星、星环、镜盾、泉滴六种轮廓。

本轮只校验提案JSON可解析与六技能参数完整；游戏导入、单测和接入验证由后续负责资源打包与QA的代理完成。

- RAW：`assets/RAW/skills/SKL-B01/v001/`，按 `motion/`、`effects/`、`icons/` 保存原始生图、原始提示词和实测布局。
- PROCESSED：`assets/PROCESSED/skills/SKL-B01/v001/`，包含角色帧、独立特效、图标、图集、精灵条、技能设计JSON、Godot SpriteFrames及合成预览。
- 角色层采用96×96、脚底根点(48,90)，中立站高约40px，沿用已接入的CHR-01比例。游戏角色节点仍按数据契约使用碰撞体中心坐标；素材脚底挂点对应中心+(0,17)，接入时需要沿用这一偏移。各原图仅校准一次统一尺度，逐帧只调整位置；身体和大型特效分别打包。
- 口部释放是奶光炮的最终美术方案；双手只做聚能与稳定架势。基础炮口挂点为角色根点+(14,-30)，允许在记录的每帧嘴点上微调。

- 奶光炮蓄力由单独的开始/增长/满蓄循环组成；发射光束另分炮口、无缝中段和头端。画面持续时长不代表持续多次伤害。
- 根点十字、参考地面线、文字和调试框只出现在预览页，不画入透明PNG。
