# 素材工具链调研（Agent 产线选型）

> 日期：2026-10-24
> 目的：为《素材设计清单》寻找**免费**的素材绘画/生成插件与工具，使 Agent 能高效产出 RAW→PROCESSED 素材。
> 结论先行：**生图入口待确认 + Pillow 后处理已验证可行 + 建议安装 photocraft/soundcraft/excalidraw 三个 ZCode 插件 + CC0 素材仅作占位**。

## 0. 现状盘点

- 本机：Linux，**RTX 5060 Laptop GPU**（本地 AI 生图硬件可行），Python 3.14.7，无 ImageMagick/GIMP/Aseprite 等 GUI 绘图工具。
- 工程：`assets/RAW/` 已有 CHR-01 玩家第一批生图（"内置 image_gen"生成，含 `.prompt.txt`/`.layout.json`）与 FX-B01 特效批次；`assets/PROCESSED/` 目录已建但**为空**，缺后处理工序。
- 注意：`素材设计清单.md` §12 进度表仍写"未调用生图"，与 RAW 实际内容不一致，待更新。
- ZCode 已装插件：image-search（参考图检索）、godot、documents 等官方 6 件；官方市场共 66 个插件。

## 1. 四条产线与选型结论

| 产线 | 推荐方案 | 状态 | 成本 |
|---|---|---|---|
| ① 生图（出 RAW） | 原"内置 image_gen"当前会话不可用 → **待制作人确认入口**；备选：本地 ComfyUI+像素画 LoRA | ⚠️ 受阻 | 免费（本地 GPU） |
| ② 后处理（RAW→PROCESSED） | **项目根 `.venv` + Pillow 13.0.0 + numpy 2.5.4**，按 `.layout.json` 切格/缩放/锚点对齐 | ✅ **已跑通验证** | 免费 |
| ③ 音频（SFX/BGM） | **soundcraft 插件**（市场未装）+ sfxr 系程序化音效 + Kenney 音频包（CC0） | 📋 待装 | 免费 |
| ④ 现成素材兜底 | Kenney（CC0）等，仅作占位与风格参考 | 📋 可选 | 免费 |

### 1.1 产线②验证记录（2026-10-24）

用 `CHR-01_cast_interact_right_v001.png`（1448×1086，4×3 网格）+ 同名 `.layout.json` 跑通最小流程：

1. 按 `columns/rows` 切出 362×362 源格；
2. alpha 包围框裁剪后**统一比例**缩放至站立高 40px（`calibration.targetStandingHeight`）；
3. 贴入 64×64 画布，脚底基线对齐根锚点 `(32,58)`；
4. 输出透明版 + 暗底合成检查版，无白边、无假透明。

与 FX-B01 README 的验收要求（统一缩放、语义锚点、alpha 检查）一致。**后续可固化为 `tools/process_raw.py`**（归属 Architect，需制作人立项后动工，本次未改工程脚本目录）。

环境备忘：pip 直连 PyPI 超时，须用镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <pkg>`。`.venv/` 已加入 `.gitignore`。

## 2. ZCode 插件（官方市场，均免费）

### 2.1 建议安装

| 插件 | 版本 | 对素材产线的用途 |
|---|---|---|
| **photocraft** | 0.2.4 | 侧栏图像编辑面板：打开工程内 PNG 裁切/修图/导出，承担 RAW 修订与 QA 检查的可视化环节 |
| **soundcraft** | 0.2.4 | 侧栏音频编辑：补上 SFX/BGM 素材缺口（清单 §11 明确音频另行准备） |
| **excalidraw** | 0.3.4 | Agent 生成草图/布局示意（房间构图、UI 线框、动作姿态草稿），可导出 |

可选：**vectorcraft**（矢量插画，图标草稿用；像素图标仍走生图/Pillow）。

### 2.2 已装可用

- **image-search**：检索参考图有效（已测试像素风 sprite sheet 检索）。⚠️ 结果多来自 CraftPix 等商店，**授权不安全，只作风格参考，严禁直接入库**。

安装方式：ZCode 客户端 `/plugin` 市场按名安装（修改客户端配置由制作人决定，Agent 不代装）。

### 2.3 市场内无关项说明

hyper3d-rodin / tripo-3d / blender / unity / unreal 等面向 3D 或其他引擎，2D 像素项目暂不需要；无生图类插件——**市场里没有能替代 image_gen 的插件**。

## 3. 免费绘画工具（人工/半人工修帧用）

| 工具 | 授权 | 说明 |
|---|---|---|
| **Pixelorama** | MIT，开源 | Godot 4.7.1 制成（与工程引擎同源），桌面/Web 版，像素画+动画时间线+精灵表导出；人工修帧首选 |
| Libresprite | 开源 | Aseprite 免费分支（Aseprite 本体付费） |
| Piskel | 开源 | 网页版，轻量快速改图 |
| Krita / Inkscape | 开源 | 通用绘画/矢量，概念稿用 |

Agent 无法操作这些 GUI；它们服务制作人复核与修订。Agent 侧的"绘画"= 生图产线 + Pillow 数值化处理（色板替换、镜像、轮廓检查均可脚本化）。

## 4. AI 生图路线对比（产线①备选）

| 路线 | 授权 | 评估 |
|---|---|---|
| 原"内置 image_gen"（已产出 v001 批次） | 按平台条款 | **当前会话工具列表中不存在**，待制作人说明入口（网页端功能？其他会话？）——本调研最大悬置项 |
| 本地 ComfyUI + 像素画模型 | 开源权重（如 RetroRetro、Flux 像素 LoRA） | RTX 5060 可跑；但开源像素模型质量与 Retro Diffusion 有差距；安装重（数 GB），Python 3.14 对 torch 生态偏新，建议届时 venv 固定 3.12/3.13 |
| Retro Diffusion（Aseprite 扩展/网页） | 付费 | 业界最优像素网格一致性，不免费，仅记录 |
| 在线免费工具（PixelMe 等） | 逐站核对 | 零散补充，商用条款需逐个确认 |
