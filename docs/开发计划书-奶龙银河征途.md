## 0. 怎么用这份文档

| 读者 | 读哪几章 | 用法 |
|---|---|---|
| 你（制作人） | 第 1、4、6 章 | 定方向、排优先级、验收里程碑 |
| 负责写代码的 Agent | 第 2、3、7 章 | 每次开工前作为上下文注入 |

| 每天开工 | 第 9 章 + 第 7.2 节任务卡模板 | 直接复制任务卡派活 |

三条铁律：

1. **先做能玩的手感，再做内容。** 角色动起来不爽，后面所有关卡都是白做。
2. **一切数值进表，不进代码。** 攻击力、掉率、经验曲线全部写在 JSON / Resource 里，改数值不改脚本。
3. **每个里程碑结束必须有一个能双击运行的构建。**

## 1. 项目概览

### 1.1 一句话定位

你扮演奶族最后的勇士「奶龙」，在森林与洞窟中找回被银河帝国夺走的「奶源」，一路夺取被封锁的能力，最终打上银河要塞、直面皇帝贝利亚。

### 1.2 设计支柱（所有争议用这三条裁决）

| 支柱 | 含义 | 反向约束（什么不能做） |
|---|---|---|
| **手感优先** | 每一次跳跃、闪避、命中都要有清晰的起手、反馈、收招 | 不做输入排队超过 2 帧的动作；不做无预警的秒杀 |
| **能力即钥匙** | 新能力 = 新地图 + 旧地图的新路径，玩家自己"啊哈" | 不做纯数值门（"需要 5 级才能开"）；钥匙必须能被玩家看见并记住 |
| **战斗可解** | 每个敌人有至少一条"标准答案"（闪避时机 / 防御 / 属性克制） | 不做无法躲避的必中技；不做纯堆血量的 BOSS |

### 1.3 目标规格

| 项目 | 本期目标 | 最终形态 |
|---|---|---|
| 平台 | Windows PC（可直接运行的 exe） | Steam |
| 分辨率 | 内部渲染 640×360，窗口 1280×720 / 1920×1080 | 同 |
| 帧率 | 60 FPS，物理 60Hz | 同 |
| 输入 | 键鼠 + Xbox/DS4 手柄 | 同 |
| 语言 | 简体中文 | +英文 |

### 1.4 MVP 与后续版本的边界

| 范围 | MVP（本期，M4 交付） | 完整版 |
|---|---|---|
| 系统 | 战斗、背包、快捷栏、天赋、商店、仓库、篝火、存档、HUD、地图 | 全部 + 成就、云存档、多周目 |
| 美术 | 灰盒 + 程序绘制的色块与描边 | 正式像素 |
| 音频 | 占位音效（可缺省，代码容错） | 9 首 BGM + 45 条 SFX |

### 1.5 团队与产能假设

- **人类**：需求决策、美术（或外包）、手感调参、最终验收。约 15 小时/周。
- **Agent 编队**：并行 2 个会话，代码与关卡/数值分离。产能约 1.5 个全职程序。
- **结论**：本期 8 周；若只求"框架 + 1 个区域"，可压到 5 周。

### 1.6 IP 提醒（30 秒）

「奶龙」为现有动画 IP，「贝利亚」为特摄 IP。**开发期做同人原型没有问题，上线售卖必须换原创角色与名称。** 建议从 Day 1 就用原创命名做工程标识（如「奶龙」→「奶宝 Naiber」、「贝利亚」→「银河皇帝·贝洛斯」），美术可后替换，避免后期大改资源与文本。

## 2. 技术选型与工程架构

### 2.1 引擎：Godot 4.4（稳定版）

| 理由 | 说明 |
|---|---|
| 场景是纯文本（.tscn） | Agent 可直接读、改、diff |
| 无 .meta 二进制负担 | 资源移动不炸引用 |
| 2D 原生 | TileMapLayer、Light2D、Camera2D、AnimationTree 开箱即用 |
| 无头模式 | `godot --headless` 可跑 CI 与冒烟测试，Agent 能自证"没写坏" |
| 导出链短 | 一键导出 exe，无授权费 |

> 若坚持 Unity：第 3 章规则、第 4/5 章内容、第 6/7 章流程全部通用，替换 2.2–2.4 的目录与组件写法即可。

│   ├── items.json  weapons.json  skills.json  talents.json  enemies.json

### 2.3 架构：三条原则

**① 单例只做全局，不做业务**

| 单例 | 职责 |
|---|---|
| `EventBus` | 全局信号（受伤、死亡、拾取、进入房间、升级） |
| `GameState` | 运行时状态：属性、背包、快捷栏、天赋、已开宝箱、已解锁能力 |
| `SaveSystem` | 序列化、双槽轮换、CRC、版本迁移 |
| `SceneRouter` | 房间切换、转场、出生点、转场自动存档 |
| `DataDB` | 启动时载入 `data/*.json`，按 id 查询 |
| `AudioManager` | BGM 淡入、SFX 池（资源缺失时静默，不报错） |

**② 组合优于继承。** 玩家与敌人共用 `HealthComponent`、`HitboxComponent`、`HurtboxComponent`、`StateMachine`、`LootComponent`。新敌人 = 拼组件 + 写状态。

**③ 数据驱动。** 敌人血量、掉落、门连接、刷怪点全在 JSON；代码里禁止魔法数字。

### 2.4 灰盒策略（本期的关键取舍）

本期**不做 TileMap、不做美术**，房间用数据描述，运行时生成：

```json
{ "id": "forest_01", "size": [2, 1],
  "platforms": [[0,340,1280,20],[320,240,160,16],[760,180,160,16]],
  "spawn": [64, 296], "bg": "#16241a" }
```

- 每块 platform → `StaticBody2D` + `RectangleShape2D` + `_draw()` 色块。
- 好处：**零美术资源即可验证手感与连通性**；JSON 可被 Agent 精确 diff；改一关卡 = 改一行。
- 替换路径：后期 `RoomData.tileset` 字段接管渲染，`platforms` 退化为碰撞层，逻辑代码一行不改。

### 2.5 物理层与渲染规范

| 层 | 名称 |
|---|---|
| 1 | world |
| 2 | player_body |
| 3 | enemy_body |
| 4 | player_hitbox |
| 5 | enemy_hitbox |
| 6 | hurtbox |
| 7 | interactable |
| 8 | oneway |
| 9 | hazard |

- 图块 16×16；玩家碰撞体 20×34，受击框 24×38。
- 摄像机：平滑跟随（lerp 8.0）+ 前瞻 40px + 房间边界钳制 + 屏震（0.15s / 3px）。
- 渲染：`default_texture_filter = Nearest`，`snap_2d_transforms_to_pixel = on`。

### 2.6 工程卫生

- Git：`main` / `dev` / `feat/*`；提交信息 `type(scope): 描述`。
- 测试：`godot --headless --script res://tests/run_tests.gd`，退出码非 0 即失败。**Agent 提交前必须本地跑通。**
- 每次 push 跑：资源导入 → 单元测试 → 15 房间冒烟（加载 300 帧无报错）。

### 2.7 环境准备（Day 1 必做，否则寸步难行）

| 事项 | 做法 | 验收 |
|---|---|---|
| 安装 Godot | 下载 Godot 4.4.x stable Windows 版，解压到 `D:\Tools\Godot\`（不要放 C 盘受限目录） | `Godot_v4.4-stable_win64.exe --version` 有输出 |
| 加入 PATH | 或直接用绝对路径调用 | 同上 |
| **修复工作区权限** | 当前 `D:\game` 存在 Windows 写入授权异常（`grantWrite(D:\game)` 失败），需把本会话切到「完全权限」或运行一次权限修复脚本 | 能在 `D:\game` 下执行 `echo ok > t.txt` |
| Git | `git init` + `.gitignore`（`.godot/`、`*.tmp`） | `git status` 正常 |

> 这一条不解决，Agent 只能"盲写代码、无法验证"，本期质量无法保证。

## 3. 游戏系统设计

> 每个小节结尾的 **【验收】** 即 Agent 交付判定标准。

### 3.1 角色控制器与行动

**移动参数（60Hz 物理）**

| 参数 | 值 | 备注 |
|---|---|---|
| 水平最大速度 | 160 px/s | |
| 地面加速 / 减速 | 1600 / 2200 px/s² | 停得要"急" |
| 空中加速 / 减速 | 1200 / 800 px/s² | |
| 重力（上升 / 下降） | 1800 / 2600 px/s² | 落得比升得快 |
| 最大下落速度 | 700 px/s | |
| 跳跃初速 | 450 px/s | 跳高 56px（3.5 格），到顶 0.25s |
| 松键短跳 | 速度 ×0.45 | |
| 土狼时间 | 0.10s | |
| 跳跃缓冲 | 0.12s | |
| 二段跳初速 | 400 px/s | 解锁后空中 1 次 |
| 闪避速度 / 时长 | 900 px/s / 0.18s | 距离约 150px |
| 闪避无敌帧 | 0.06s – 0.17s | 起手 3 帧非无敌 |
| 闪避冷却 | 0.45s | 空中闪避独立 1 次 |
| 闪避体力消耗 | 12 | |
| 防御减伤 | 60% | 移速降为 40% |
| 防御体力消耗 | 伤害值 × 1.2 | 体力不足破防，硬直 0.6s |
| 完美格挡 | 按下后 0.12s | 不耗体力 + 反弹 30% + 敌硬直 |
| 受击无敌 | 0.8s | 闪烁提示 |
| 受击击退 | 180 px/s，硬直 0.2s | |

**状态机**：`Idle → Run → Jump → Fall → Land → Hurt → Dodge → Guard → Attack → Skill → Dead`。状态只改 `velocity` 与自身计时器，禁止跨状态直接改别的组件。

**多段跳层级**：Lv1 单跳 →「奶泡跃」二段跳 →（后续）天赋三段跳。

**【验收】**
1. 走出平台 100ms 内按跳能起跳（土狼）。
2. 落地前 120ms 按跳，落地瞬间起跳（缓冲）。
3. 贴墙不粘墙，水平速度不被吞。
4. 跳跃最高点误差 ≤ ±2px（自动化用固定步长模拟）。
5. 45° 斜坡不抖、不下滑。
6. 单向平台可上穿、按住 ↓ 下穿。
7. 输入到动作延迟 ≤ 1 帧。
8. 闪避穿过敌人攻击判定不掉血。

### 3.2 属性与资源

| 资源 | 初始 | 成长 | 回复 |
|---|---|---|---|
| HP | 80 | +4/级；碎片 +10 | 篝火、药剂、天赋 |
| 体力 STA | 100 | 固定；碎片 +5 | 停手 0.8s 后 12/s |
| 奶力 MANA | 60 | +3/级；碎片 +8 | 击杀 +2、篝火、药剂 |
| EXP | 0 | — | 击杀、宝箱 |
| 奶币 | 0 | — | 掉落、宝箱、卖道具 |

**死亡**：HP=0 → 1.5s 演出 → 回最近篝火，HP 满、体力/奶力半满；掉落 30% 奶币形成「奶滴」，可回收一次；敌人重生。

**【验收】**：三条资源独立更新；体力不足无法闪避/防御；死亡流程与奶滴逻辑一致；HUD 数值 0.15s 插值。

### 3.3 战斗系统

**四象限伤害类型**

| | 近战 | 远程 |
|---|---|---|
| **物理** | 锤击、冲撞 | 奶弹枪、投掷 |
| **法术** | 奶杖横扫 | 法球、追踪奶泡 |

**武器决定普攻**

| 武器 | 普攻 | 类型 | 攻速 | 特点 |
|---|---|---|---|---|
| 奶瓶锤 | 3 段连击 | 近战物理 | 慢 | 高伤、击退强、破盾 |
| 奶弹枪 | 单发/蓄力 | 远程物理 | 中 | 蓄力满穿透 |
| 奶杖 | 横扫 | 近战法术 | 中 | 命中回 3 奶力 |
| 星乳法球 | 慢速弹 | 远程法术 | 慢 | 命中分裂小奶泡 |

**命中流程**（统一走组件）：
`起手 → 激活 Hitbox（带 DamagePacket）→ 与 Hurtbox 相交 → 结算（减伤/无敌/击退/闪白/音效/屏震）→ 伤害飘字 → 顿帧 0.04s`

**伤害公式**

```
最终伤害 = (武器攻击 + 8 + 2×(等级-1)) × 技能倍率
         × (1 + 天赋/道具加成%)
         × 类型克制（弱点 1.5 / 抗性 0.6 / 免疫 0）
         × (1 - 防御 / (防御 + 120))
         × 暴击（1.5）
         × 防御减伤（格挡 0.4 / 完美格挡 0 并反弹 30%）
```

**本期敌人抗性**：苔甲虫（物理 0.8）、暗影奶灵（法术 0）、酸液蛞（物理 1.2 / 法术 0.6）、蜂蜜女王（法术 0.5）。

**【验收】**
1. 四武器切换后表现/音效/判定区分。
2. 物理 vs 法术伤害与抗性表一致（断言）。
3. 无敌帧内受击伤害为 0 且不硬直。
4. 防御按 伤害×1.2 扣体力；归零破防。
5. 完美格挡反弹并给敌 0.5s 硬直。
6. 顿帧期间输入被缓冲、结束后执行。

### 3.4 等级与成长

- 初始 Lv1，**上限 Lv15（本期）**。每级 +1 天赋点，提升 HP/奶力/攻击（见 5.1）。
- 经验：`XP_to_next(L) = round(28 × L^1.62)`。
- 升级演出 0.8s 无敌，不打断战斗。
- BOSS 首杀额外 +1 天赋点。

**【验收】**：经验溢出可连升；满级后经验不增长且不报错；面板数值与实际一致。

### 3.5 天赋树（本期 12 节点）

三分支各 4 节点，消耗**天赋点 + 奶币**双资源。

| 分支 | 节点（层级 1→4） |
|---|---|
| **蛮力**（物理） | 重锤精通（物攻 +15%）→ 破甲（无视 20% 防御）→ 嗜血（击杀回 3 HP）→ 钢铁之躯（受伤 -10%） |
| **奶术**（法术） | 奶力涌动（上限 +20）→ 法术穿透（法伤 +12%）→ 节流（技能奶力 -15%）→ 溢乳（技能命中回 2 奶力） |
| **灵巧**（机动） | 疾影（闪避冷却 -30%）→ 铁壁（防御减伤 70%）→ 乳步（移速 +10%）→ 三重奶泡（三段跳，本期预留） |

规则：同分支按层级解锁；跨分支无前置；**200 奶币重置**（退天赋点，不退奶币）。

**【验收】**：前置未满时灰显 + 提示；重置返还正确；加成实时生效。

### 3.6 奶术（本期 5 个）

| 技能 | 类型 | 奶力 | 冷却 | 获取 | 效果 |
|---|---|---|---|---|---|
| 奶泡弹 | 远程法术 | 8 | 0.6s | 初始 | 直线弹，命中减速 30% |
| 奶盾 | 增益 | 15 | 8s | 天赋·奶术 2 | 5s 内吸收 40 伤害 |
| 挤奶冲击 | 近战法术 | 12 | 1.2s | 洞窟宝箱 | 前方扇形 1.5 倍 + 击退 |
| 治愈之乳 | 治疗 | 25 | 12s | 商人 | 回复 30% HP |
| 星乳坠落 | 爆发 | 30 | 15s | 天赋·奶术 4 | 天降 3 段范围伤害 |

> 后续版本补：奶雾、奶化、奶龙咆哮、引乳钩索、净化之乳（数据表已留位）。

**【验收】**：奶力不足灰显；冷却扇形；技能可被闪避取消后摇。

### 3.7 物品、背包与快捷栏

- **背包 15 格**，可扩容 3 次（+5/次，本期只放 1 个扩容道具在洞窟隐藏区）。
- **快捷栏 5 格、不可改变**：只能放已登录的消耗品/投掷物；登录 = 背包界面拖入。
- 武器独立装备槽；材料独立页。
- 堆叠：消耗品 5 / 材料 99。
- **仓库**（篝火）：无限格，存取守恒。
- 死亡不掉物品（只掉奶币）。

**【验收】**：背包满时保留地面掉落并提示；快捷键抖动不丢图标；仓库存取守恒（自动化断言）。

### 3.11 地图与房间流转

- **房间** = JSON 条目，尺寸为 640×360 的整数倍（1×1、2×1、1×2、2×2）。
- **门**：`{id, pos, target_room, target_door, one_way?}`；切换走 `SceneRouter`，0.25s 黑场。
- **区域**：决定 BGM、配色、敌人表。
- **小地图**：由房间 `map_rect` + 门连接自动生成，未探索隐藏。
- **能力门**：`{requires: "double_jump"}`，未解锁时显示锁标与提示。

**【验收】**：切房后玩家对齐目标门（误差 ≤ 4px）；返回状态保留；小地图实时更新。

**【验收】**：打死玩家后脱战回位；击退不穿墙；词条可在数据里勾选。

### 5.2 敌人数值（本期只有 2 个等级段）

```
小怪 HP   = (20 + 10 × 区域等级)
精英 HP   = 小怪 × 8
BOSS HP   = 小怪 × 45
伤害      = (4 + 2 × 区域等级) × 档位系数(1.0 / 1.6 / 2.2)
防御      = 5 + 3 × 区域等级
```

| 区域 | 小怪 HP | 精英 HP | BOSS HP | 小怪伤害 | BOSS 伤害 | 玩家预期等级 |
|---|---|---|---|---|---|---|
| ① 林地（tier 1） | 30 | 240 | — | 6 | — | 1–6 |
| ② 洞窟（tier 2） | 40 | 320 | 1,800 | 8 | 18 | 6–12 |

**TTK 校验**：玩家期望 DPS ≈ 12 + 4N（N 为区域等级）→ 小怪 1.9–2.4 秒，精英 15–18 秒，BOSS 90–100 秒。偏离先改敌人 HP，不动手感参数。

### 5.3 平衡校验（可自动化）

`tools/balance_sim.py`：读 `data/enemies.json`，模拟玩家 vs 敌人，输出 TTK 表并断言：
- 小怪 TTK ∈ [1.5, 5] 秒
- BOSS TTK ∈ [90, 150] 秒
- 任何区域的小怪伤害 < 玩家该等级 HP 的 15%

## 附录 D：术语表

| 术语 | 含义 |
|---|---|
| 灰盒（Greybox） | 无贴图、只用色块与碰撞体的可玩关卡 |
| 垂直切片 | 一小段但系统完整的可玩版本 |
| 土狼时间 | 离开平台后仍允许起跳的宽限 |
| 无敌帧 | 受击无效的时间窗口 |
| TTK | Time To Kill，击杀所需时间 |
| 能力门 | 必须有特定能力才能通过的地形 |
| 单向门 | 只能单向通过的门（捷径用） |
