## 解谜一：05

### 05A 分水根庭

入口能看到隔水的底渠和上层闸室，使玩家先理解“那里最终能过去”。初始中渠有水、根井下段封闭，入口侧始终可退。

1. 在低位操作A，让中渠水位下降，露出通往根井的台阶。
2. 沿左井和中层折返向上，到达B；透过根间空隙能看到水位变化。
3. 操作B排空底渠，打开G，接通02接口；上层支路通向R和08接口。
4. 以后01—02直接走底渠，不再爬两口井。二段跳可以从中层根脊进入B背面，用于回访和另一方向进入时缩短路径。

水位只影响机关可达性，不设计溺水消耗。A/B都有复位柄；落入底渠能沿检修台阶返回入口。两阀完成状态与G永久开启状态分别保存，复位解谜不得重新锁住已开捷径。

### 05B 双篮树井

两口树井、中层交换站和底层直廊形成三个可互相观察的位置。核心是移动设备位置，而非猜密码。

1. 入口A将配重接入左篮，左篮从下层运人至中层。
2. 在交换站B换接配重，让右篮到达中层；玩家沿中层横廊走到右篮。
3. 右篮升至上层，通向奖励和08；从B背面开底廊G，接通02。
4. 二段跳获得后可利用两井间高根窝短接，不必等待篮筐。

这是拟新增的配重机关，当前未实现。每层设召回柄；召回时先恢复篮位再恢复可搬配重，玩家脚下不能被撤空。没有站在篮筐上也能完成召回；各停靠位保留固定退路。最终机关外形与操作提示在选案后一起评审。

## 解谜二：06

### 06A 折光菌窟

光源在上层，镜座在下层，接收器在东侧；两者之间隔着不能穿人的石壁，保留透光小窗。图中金线表示光束，不是行走通道。

1. A启用光源，玩家能在下方墙面看到光斑指向B。
2. 下井到B，镜座只有几个固定方向，逐档转向即可观察光斑变化。
3. 从中层窗口观察C，光束命中后门与接收器同步发光，打开奖励门G与上廊门G2。
4. 回程改走上廊，形成02—03的短路；二段跳高菌台增加中窟—C背面的接近路线。

光束不伤人。镜座可原地重置，接收成功状态永久保存；从03或09反向进入时，也能走固定下井路径到B，不在门后形成软锁。实施时接收器应在至少两个观察点可见，不让玩家每调一档都跑完整条路。

### 06B 风息风琴

上层送风、中层回流、下层检修形成一套能目视追踪的管路。图中浅蓝细线表示风管，实际位于背景，不是斜坡或可站立平台。

1. A把风导向回流支管，第一片风叶转动。
2. 到下层B打开回流，第二片风叶转动；错误档位只有漏风声与停转提示。
3. 在C调整排风，第三片风叶稳定转动后抬起G，接通03方向，并永久打开直行上廊。
4. 下层检修道通向奖励与09；二段跳从回流腔高根台进入上廊，增加跨层回访路线。

检修道始终接回入口。机关错误不扣血、不推入深坑。三阀每个都有明确初始档，不采用全隐藏状态的排列组合；只让玩家观察一条风路的断点。

## 跑酷：07

### 07A 断冠攀环

三段上升围绕粗根展开，路线从左下绕到中央，再上到右侧树冠。中段A是歇脚台；其下有宽兜底层。

第一段教交错跳台，第二段加跨坑落点，第三段组合水平跨越与攀升。达到A后从背面放下根桥G，入口可经底层直达中段。上段失败落回中环，避免每次重走第一段。主奖励在04接口之前，普通跳跃即可取得；树冠上另一道高口才要求二段跳，并连到08。

### 07B 裂谷折返

入口先向下看见谷底和对岸奖励，体验以受控下落开始。沿西裂壁下降，经谷底横跨，再从东岸攀出；空间顺序与07A相反。

沿途布置分层接住坠落的固定台，谷底可原路分段爬回。东岸拉柄放下上桥G，直接回入口；以后去奖励或04不再下谷。二段跳从东岸上廊跨入更高的08接口。主路线不依赖冲刺、空中技能或移动平台。

两案均以实际普通跳跃高度约112世界单位为校准：常规升高先按80～96布局；能力口目标约160，选案后必须用游戏物理实测。草图线条没有精确表达角色碰撞尺寸，不能据此宣布已经可跳通。先逐段验证，再加入树根、菌簇等装饰，薄平台上不得放置改变落脚轮廓的装饰。

## 战斗一：08

### 08A 苔甲三庭

三处宽平地依次承担近战读招、近远配合、精英考验。庭院之间留短安全廊，可以看到下一场而不会被远程怪从入口贴脸攻击。每庭有后退空间和少量低台，主地面不布陷落坑。

清场解开对应封印。第三庭完成后开放上层巡护廊G3，以及连接07的高台封印G4；未清场时，即使已有二段跳也不能越过上廊跳过守门战。此后02—05走上廊回访，奖励放在第三庭后安全区。

### 08B 树心双层堂

入口是西下厅的近战场，沿宽井/短阶去东上厅面对远近组合，再落回出口层。两个宽厅承担战斗，竖向连接只用于换场，不把强战斗塞在细窄台阶上。

到东厅前，从背面解除下廊G1，复战时可由篝火快速到东厅准备区。东厅清场再开G2/G3，出口层奖励与07高口开放。厅内用低根柱切断射线，避免复杂连续跳台；高台适合观察和回访，不作为站桩无伤点。

## 战斗二：09

### 09A 断根哨营

从西哨进入，下行进入两块围场；第一场是地面怪与藤鞭花，第二场是苔甲卫。两场之间的短廊用于换节奏，至少各保留一侧无坑后撤。

抵达东哨并清场后开G2/G3，上层走廊永久连通，未来03—04无需再次穿围场。二段跳从围场的高瞭望台接到上廊；初访仍受同一封印约束。下层小藏室R2是额外奖励支路，06接口可作为另一方向的进入点。

### 09B 盘根防线

外防线后直接给两种选择：中庭宽平地强攻精英，或下沟应付分散小怪与藤鞭花，从东侧绕回。两路在东门会合，不强迫两路都清一遍。

中庭胜利或下沟推进完成，都能从东侧开启对应回廊门；之后03、06、未来04可在此分流。二段跳登上残壁哨楼，形成第三条回访路线；上层封印G3和未完成战斗的出口共用状态，能力不能跳过仍然封闭的门。敌人有活动边界，不追入狭窄返井或堵住召回点。

## 能力锁与建造门禁

目前工程明确存在的移动能力是double_jump，本批只以二段跳作为实际候选能力锁。破墙、钩索、游泳、冲刺穿栅等尚未确认的能力没有作为必需条件。

每处能力锁都要同时满足：先看得到另一侧；普通跳跃达不到；现有闪避/攻击位移/边缘踩点也绕不过；没有能力仍可返回；获得能力后新路线确实缩短跨图距离。宝箱/门位置、平台净空和敌人站位在选案后需要重新实测，图上D不是仅贴一个提示图标就算完成能力锁。

十案已按追加要求先做独立试玩。后续顺序：制作人实际游玩、各选一案并提修改 → 更新草图与试玩场景 → 确认最终方案 → 才接入正式地图与世界登记 → 验证双向入口、首次路线、捷径前后、能力前后、死亡/读档 → 补齐同像素密度且正确贴地的forest装饰 → 最终验收。独立试玩没有改正式房间、存档或现有地图出口。
