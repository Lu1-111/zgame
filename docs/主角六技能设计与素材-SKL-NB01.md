# 主角六技能设计与素材 · SKL-NB01

制作人设定日期：2026-10-26。批次版本：v001。

本批收录制作人另行指定的六个技能，与 SKL-B01 的六招并列保留，共计十二项技能素材。设计数值的唯一来源为 `data/skill_designs/SKL-NB01.json`，未知值保留为 `null`，没有擅自补齐伤害、距离、光球速度或互斥规则。

现有开发计划书 §3.6 与 `data/skills.json` 仍为五技能，当前武器表也未注册剑类。本批交付设计与美术候选资源，不改变当前战斗、解锁、键位或四个技能槽；六技能如何进入本期、剑类武器及互斥规则需在玩法接入时与制作人统一。

## 美术方向

沿用 CHR-01：黄色圆润身体、奶油色肚皮、绿色眼圈、深色手脚、短尾；右向横版像素表现。居合用白银弧光，重砸用奶白/蜜金冲击与碎石；虚式用奶白球心和浅紫蓝轨道。持续状态严格保持红 / 白 / 蓝区分。

角色图与独立特效分组存储；角色源稿中的少量手部施法光、落地尘和剑光保留，因此对应阶段不应重复叠加同一整套特效。持续气流、状态粒子、光球、爆炸、法阵、眩晕均有独立帧组。原稿不是精确网格，切帧以显式来源矩形与锚点清单为准。

透明 PNG 中 Alpha 为零区域可能保留不可见 RGB；检查以实际 Alpha 合成到暗 / 明底为准。最近邻取样；翻面应以清单 root 为轴。角色身体尺度接近现有 CHR-01，含武器的动作扩大透明画布，不能按包围框逐帧缩放角色。

## 玩法接入要点

1. 拔刀仅免除触发反击的这次受击，不应自动变成全程无敌；无目标、目标失效与索敌范围保留待定。
2. 狂击的伤害提升和易伤同时生效。击杀回复发生在确定击杀时，不绑定大笑动画；血量计算基准待定。
3. 王从天降的晕眩禁止行动；精英/BOSS免疫、空中能否施放及是否破坏碰撞地形待定。碎石素材本身只提供视觉，不改地形碰撞。
4. 忍耐生效期间禁止闪避；结束时恢复常规闪避。与狂击的互斥范围和切换策略待定。
5. 虚式需要独立光球实体和再次按键指令。飞行计时从释放开始，爆炸可手动或超时触发，结算只能发生一次；冷却从爆炸时开始。方向采样时点、穿透、撞墙、接触多段、切房回收待定。
6. 奥术只改普通攻击的伤害类型；原本为奶术的普攻只获得指定加成，不应同时再套一层转化。其他技能不自动受该转换影响。
