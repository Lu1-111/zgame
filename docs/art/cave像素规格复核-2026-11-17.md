## 本次转换

使用Pillow/NumPy实现的`tools/assets/pixel_grid.py`，不是重新让图像模型生成“像素风”大图：

1. 按母版图集格切出源区域、去除低alpha的源边缘。
2. 从源区域一次面积采样到已登记的最终整数像素网格。透明素材先预乘alpha，避免黑边；中间平均色不会作为最终颜色保留。
3. 投影到统一32色色板；硬边alpha只留0或255，清理游离噪点。不同状态不反复缩放。
4. 在固定画布上补透明边、登记接地锚点。闭箱与锁箱只在锁块内有差别。
5. 运行时nearest、无mipmap、前景scale=(1,1)，岩壁着色器采样尺寸与文件像素数一致。灯光渐变是单独PointLight层，不烘焙进贴图。

逐图源尺寸、裁切、采样尺寸与次数记录在[audits/cave_pixel_conversion.json](audits/cave_pixel_conversion.json)。原生对照图仅裁透明边：上排是实际1倍像素，下排4倍nearest用于检查，4倍图片不供运行时使用。

## 后续每次必须执行

- 新增或修改美术前先读AGENTS.md基本原则与`data/art/pixel_standards.json`。
- 在本批JSON登记目标画布、调色板、锚点、世界尺寸与运行缩放。参考本批`data/art/cave_v001_pixel_spec.json`。
- 高清/AI图先工具转换再接入，不能只改DPI、缩放节点、开nearest或用大色块画风冒充原生像素。
- 必须跑像素门禁，并查看实际1倍画面及整数倍放大图；自动统计本身不证明美术质量。

```text
python tools/qa/validate_pixel_assets.py --manifest data/art/cave_v001.json
python tools/qa/audit_pixel_density.py
```

门禁检查实际文件像素数与登记一致、每套不超过32色、硬alpha、无mipmap、1:1运行声明、一次原生网格转换记录；Godot场景测试额外核对背景、地形、角色、物件的实际scale及岩石场采样尺寸。
