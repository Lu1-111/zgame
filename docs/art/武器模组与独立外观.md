# 武器模组与独立外观

2026-11-17制作人要求：动作中去掉具体武器，在原位置保留占位；后续由装备类型决定攻击模组，把具体武器放到动作挂点上。

## 当前实现

动作资源已拆成去武器身体、逐帧握持位置/方向、具体武器层和掌指前景。运行时按相同帧号合成并缓存，仍播放逐帧PNG，不用细线手臂或运行时骨架代替原人物动作。占位模式用小十字标记握点；装备已有模型时装上对应武器。正式装备仍显示原武器，原模型并未从工程中丢弃。

四类普攻（剑、锤、杖、步枪）、四类格挡，以及拔刀和重锤限定技能共16套动作、76帧纳入此结构。步枪瞄准继续使用既有身体/手臂姿态与握点，具体枪形移到独立数据模型；新枪形可用原生贴图提供。没有把通用法术自身的法球、剑光或召唤物误当作装备武器删除。

装备表data/weapons.json中的两项分工明确：

| 字段 | 用途 |
|---|---|
| weapon_type | sword / hammer / staff / rifle，选择原战斗模组 |
| appearance_id | 选择具体武器模型，现有原版为original |

外观系统不读取或覆盖攻击力、攻速、连段、削韧、判定框、弹幕速度/源点。换一把更长的外观也不会扩大命中范围。旧存档只保存装备ID，加载后由装备表读取外观，无需存档迁移。

## 此后挂接新武器

1. 先按AGENTS像素原则制作真正的原生武器PNG，完成专用工具转换与1×/4×查看。模型JSON登记id、name、weapon_type、texture、native_canvas、grip和source_angle_degrees。native_canvas与实际W×H必须相同，grip为这张图上手掌接触的原生像素坐标。
2. 运行tools/assets/attach_weapon_model.py --model <模型JSON> --output-dir <新目录>。工具读取已有动作握点和朝向，只进行1:1最近邻方向采样，生成该类型全部普攻/格挡/限定技能的独立武器帧；不会缩放或修改人物。越界、软alpha、超32色、不匹配的分辨率或重复输出都拒绝。
3. 检查生成帧、手掌遮挡和挥动净空。确认后用位于assets/PROCESSED/weapons下的正式输出目录加--register登记；新appearance_id自动加入表现清单，人物帧无需重画。再在对应装备条目填写weapon_type和appearance_id，不改原攻击模组。
4. 将正式新层按像素包登记并跑像素/角色测试；重新导入工程。基础拆分重建会保留画布/握点未变的已注册模型；如果动作画布或握点改变，该帧显示占位，需要重新挂接。同一模型定义可导出到新目录后再次--register，不同定义须使用新ID。模型JSON和独立bank.json必须保留。

工具已用独立8×3原生测试模型实际生成剑类型35帧、6套动作，试验保存在work/qa/weapon_model_trial。2026-11-18新增九把武器已按制作人设定分别接入，详见[武器登记表](../gameplay/武器登记表.md)。五把剑、四把锤的像素画RAW经ImageMagick Point转换为48×24原生模型，共267张同画布逐帧挂接层，人物画布与身体像素不变。阔剑、落英、流星锤、巨剑使用补充结构细节后的版本。原图与完整提示词在assets/RAW/weapons/{ID}/v001/generation.json，转换记录在data/art/weapon_conversion_v001.json。

武器数值由data/weapons.json与weapon_attributes.json控制，外观配置继续只决定显示。基础削韧、阶段时间按武器倍率应用于普通攻击，技能独立。实际时序与分段/连招测试入口为test/launchers/run_weapon_combat.cmd；可选择13把现役武器，重播、循环与切换朝向。
