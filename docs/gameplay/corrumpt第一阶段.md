# corrumpt · 克拉弗特第一阶段

当前实现记录：2026-11-12。运行ID为`corrumpt`，显示名“奶化病毒催化体-克拉弗特”。数值来源为`data/bosses/claffert.json`及`data/boss_rules.json`；修改后用`tools/data/sync_enemy_registry.py`同步怪物记录表。

第一阶段在独立演练场`test/scenes/previews/corrumpt_arena.tscn`实现，可双击`test/launchers/run_corrumpt.cmd`测试完整双阶段。600基础生命耗尽后清理旧攻击并播放绽开、枯萎、升空、紫光转场，再进入1000生命的二阶段，详见`corrumpt第二阶段.md`。尚未放进正式地图。

## 当前尺寸与共同本体

正式版本为`assets/PROCESSED/enemies/BOSS-CLAFFERT/v005/`。本体保留已确认帧，触手和六类效果重绘为与花苞一致的细纤维、黑纹和阴影；必要母版保存在`v005/sources/approved_reference/frames/`，弃用版本已移出仓库。

| 项目 | 当前规格 |
|---|---|
| 玩家闲置alpha可见高度 | 42px |
| Boss本体alpha可见高度 | 84px，约两个角色高 |
| Boss本体可见宽 | 68px |
| 本体画布 / 固定根座 | 128×128 / (64,112) |
| 运行像素比例 | 1原生像素=1世界单位，scale恒为1，nearest |
| 色板 | 全套共用32色，无抖动、二值透明 |
| 长触手伸展 | 238px，约3.5个本体宽 |
| 触手举高 | 相对连接点160px，高于花苞冠顶 |

花苞简化为三片闭合紫瓣、少量黑纹和短根。所有招式共用同一个持续播放的八帧心跳本体。攻击开始、结束和左右方向切换，都不重置其帧及帧内进度；只有触手层改变姿态和方向。本体不镜像，不按各动作包围盒分别标定大小，因此换状态不会突然翻转纹样、改变颜色或体型。

触手同样是绘制的PNG逐帧资源：独立图集提供待机、伸展高举、六帧下挥、入地和撤回姿势。运行时只有SpriteFrames层，没有骨骼、网格或程序姿势变形。八帧心跳的0/1原生像素脉动已离线烘焙；根座不变。所有完整合成对照帧逐像素验证共同本体相同；运行测试另验实际AnimatedSprite2D在切招时保留同一贴图、帧和播放进度。

`v005/sources/`保留内置imagegen的共同母版、触手图集、单独高举触手和六类特效图集；`PROMPTS.md`记录完整调用提示词。`tools/assets/build_corrumpt_unified.py`调用ImageMagick完成真实采样、限色和固定根座装配，Pillow只读分析源图。触手仅等比采样，禁止分别拉长两个轴；两阶段本体逐字节复制自上述已确认母版。当前重建入口不再依赖弃用版本。

针弹40×16、孢子20×20、地刺32×40、砸地冲击236×32均按原生纹素显示，不按每帧包围盒再缩放。引力环、震退环采用96×12环带四帧纹理，在1世界单位网格上沿周长采样，扩散只改变半径，纹素大小和环带线宽不变。固定基线和主轮廓源框避免散落粒子导致的对齐与大小跳变。实际材质对照见`docs/previews/corrumpt_effects_v5.png`。

两根触手实体始终保留。待机使用同一根端母版作细微幅度变化；按根端连通块截取整根，排除相邻格的零散像素，不再因包围盒被撑大而缩没。地下阶段保留地表根端。主招式只驱动玩家所在一侧，另一侧持续待机；左右转向不镜像本体。

第二阶段先将正面三层刀瓣、无根花体的外形和八帧闲置转换为当前规格，再制作延长/旋转/收回与气流，现已接入战斗。独立资源包`phase2_v001/`不覆盖一阶段母版。

## 六招与时序

| 招式 | 倍率1.0时伤害 | 行为 |
|---|---:|---|
| 砸击 | 20 | 举起0.45s，停顿0.2s，六帧挥落0.5s，落地表现0.18s，收回0.55s；全程按触手轮廓接触伤害 |
| 地刺 | 每道25 | 先播放危险红光，消失1.5s后从近到远每0.2s生成一道；入地动作包含在1.5s内；8道、宽/间距均32px，每道独立存活0.4s |
| 针弹 | 每针5 | 40×16原生尺寸，10枚同源点扇形发射，第6枚中央针瞄准当时玩家，相邻间隔15°，全程不追踪，撞实体或地图边界消失 |
| 引力 | 0 | 圆环扩散至屏幕外，强制拉向Boss并造成一次无伤硬直 |
| 孢子囊 | 每球10 | 每波7个随机方向弹幕，触及墙体及空心平台两侧按法线反弹；第二次碰撞、满8秒或命中玩家后消失 |
| 震退 | 0 | 极近距离累计4s后立即向外推开至砸击/地刺范围之外，无额外冷却；圆环仅作表现 |

砸击、地刺起手时按玩家所在侧锁定左右，中途不换侧。砸击的左右Area2D实体由当前PNG的alpha轮廓生成凸分解碰撞体，轮廓随逐帧动作和方向同步；上升、空中及下落均可被命中，弧线内部空白不误伤。同次砸击持续接触只命中一次；落地冲击图仅作表现，不再另扣一次血。地刺在近于半射程时仍保留候选，首道起点取默认50px与玩家水平距离的较小值，避免近身起点空区；可跳跃躲避，各道伤害和寿命独立。飞针按40×16胶囊体扫掠，擦到实体也命中，避免仅中心线检测。当前有伤招式暂按物理类型登记。

碰撞体、攻击距离、层高容差、速度和非指定时序为JSON中的调试值：本体碰撞56×80，近战判定距离280px；后续可继续调平衡。

## AI与韧性

- 准备态每满1s判定1/3攻击概率；主招式结束冷却2s，随后重新准备。
- 同层近战范围内砸击/地刺/针弹权重40/40/20；范围外针弹/孢子/引力30/30/40。孢子与另外两个远程招式共用选招条件和主冷却，不再有独立概率或滞留寿命。
- 玩家从范围外进入同层近战范围时，准备/冷却态立即等概率施放砸击或地刺，结束后正常冷却2秒；已经开始的招式或瘫痪不被进入范围重复打断。
- 引力结束立即重新检测距离；进入近战范围则等概率接砸击/地刺，接招结束才冷却。
- 玩家处于极近距离的时间累计到4秒，立即独立震退并清零累计；离开暂停累计，无额外冷却，不重置主技能计时。施法期间也可触发，瘫痪期间不累计。推力按当前距离动态计算，推出砸击与最远地刺范围外。
- 主招式期间仍受生命伤害，韧性锁定；可破韧期清空韧性后中断行动，按`1+韧性×0.01`瘫痪（一阶段4秒），受伤增加30%。重复受击不重置瘫痪；结束恢复300韧性并立即攻击。
- 闪避无敌仍可避免伤害和无伤控制；强制位移经角色物理移动处理。

专用首领血条在屏幕上方偏左居中显示，不显示头顶血条；最后一击生命和残血过渡同时归零。
