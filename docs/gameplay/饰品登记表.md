# 饰品登记表

在人物面板（I）的装备页打开「饰品」，将图标拖到右侧的饰品槽。角色有两个饰品槽。物品描述、效果字段和贴图路径见 [accessories.json](../../data/accessories.json)。

| ID | 名称 | 效果 |
|---|---|---|
| `accessory_01` | 铭牌 | 伤害 +5% |
| `accessory_02` | 回春护符 | 生命上限 +5%，回复量 +25% |
| `accessory_03` | 锈蚀之剑 | 近战伤害 +8% |
| `accessory_04` | 腐朽之弓 | 远程伤害 +8% |
| `accessory_05` | 破败之盾 | 伤害减免 +8% |
| `accessory_06` | 弑血护符 | 流血伤害 +50% |
| `accessory_07` | 追猎 | 破韧后下一次攻击伤害 +20% |
| `accessory_08` | 弹丸腰带 | 每次枪械射击有 1/3 概率免耗弹药 |
| `accessory_09` | 豪情 | 闪避结束后 1 秒内伤害 +10% |
| `accessory_10` | 战意披风 | 每损失 1% 生命，伤害 +0.3% |
| `accessory_11` | 能量立方 | 当前装备机械武器时伤害 +10% |

本批原型物品首次载入时发放一次，后续装备与持有状态随旅途存档保存。能量立方读取当前唯一装备武器的机械分类。弹丸腰带按一整次射击判定，霰弹枪三发共享该次判定。
