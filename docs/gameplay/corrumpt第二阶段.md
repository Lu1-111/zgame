# corrumpt 二阶段实现

唯一数值来源：`data/bosses/claffert.json`，首领通用破韧公式在`data/boss_rules.json`。600基础生命的一阶段耗尽后清理残留攻击，先播放转阶段过场，再进入1000基础生命二阶段；二阶段归零后还需完成“虚空湮灭”，玩家存活才结算击败。基础攻击10、一/二阶段韧性300/450、双抗0，按区域倍率只缩放基础生命/基础攻击。

先完成外形和闲置标准化：128×128画布、花心(64,64)、1:1纹素、32色、八帧8fps。导入与花心一致性验证通过后，才生成延长刀瓣与气流；完整来源见`assets/PROCESSED/enemies/BOSS-CLAFFERT/phase2_v001/`。

## 行动模式

- 巡空：保持较远距离及高度差，在候选落点检测实心墙体并优先选择空闲位置；允许穿过墙体/平台。常态移速不超过玩家常态移速（当前160px/s，实时含天赋）；每次招式完成后3秒，按各50%概率选飞针/孢子。第三次施法完成后等待4秒，切近身。
- 近身：进入立即选择旋刃，之后按“冲击、冲击、冲击、旋刃”执行。完整收招后先降落至脚下地面或空心平台，花体底部贴合表面，再进入4秒硬直；硬直期间受到的削韧提高到2倍，生命伤害不翻倍。结束后以原规则调位并发动下一招。末次旋刃完成后立即回巡空，四秒窗口只位于两次近身招式之间。

近身不再使用旧的侧面5秒待机；2026-11-12改为明确的落地恢复窗口。降落速度240px/s，硬直只在落地后计时，不随受击重新计时；若期间破韧，改用5.5秒瘫痪，恢复后立即调位接招，不补等四秒。
- 两种模式在每次施法前，均以玩家2倍常态移速调位一次，锁定本次起手点。施法期间只执行招式自身位移，不额外追随玩家。预调位不叠加近身75%减速；近身招式内部所有位移（对齐、后撤、冲撞、换边收招）统一为原速度的75%。
- 巡空间隔从上一次完整招式（含全部弹幕轮次、收招）结束时计，长招式不叠放；近身硬直从落地时计。施法与调位仍可穿地形，只有降落恢复会查询脚下可站立表面。所有位置以花体半径留出地图边界余量。

## 招式

旋刃：起手前调位至玩家左上方(-200,-160)，0.5秒延长刀瓣、0.25秒加速旋转；每段停顿1.5秒后锁定当时玩家方向，按675px/s（900×75%）直线冲撞420px；遇地图边界提前停止。随机循环3～5次，后续只停顿/冲撞，不再调整到左上方。完成后0.3秒减速、0.5秒收瓣恢复常态。每段冲撞最多造成一次1.5攻击力（当前15点）伤害及大幅击退。

冲击：起手前调位至玩家一侧160px，同水平面；向远离玩家方向后撤70px，停顿0.2秒后向玩家所在侧水平冲刺480px，速度862.5px/s（1150×75%）。接触一次造成2.0攻击力（当前20点）及大幅击退。自起手至攻击结束后的换边收招全程可穿玩家；完成后随机移动至玩家一侧180px处，收招速度562.5px/s，若直线路径会接触玩家，则在边界允许范围选择较短的上/下绕行路径。

两种冲撞都以扫掠胶囊判断接触，避免高速穿过而漏判；冲撞段关闭对玩家的实体阻挡。大幅击退700px/s、0.35秒，通过玩家正常伤害、格挡、闪避/无敌结算后才施加，不绕过无敌。破空气流随冲撞方向显示在花体后方。

飞针：共4轮，每轮10枚，轮间隔0.7秒；每发0.2攻击力（当前2点）。沿用40×16纹理。每轮发射瞬间，以Boss顶端为共同扇形原点，第6枚（10枚中间偏右）瞄准当时玩家位置，其余相邻15°，偏角为-75/-60/-45/-30/-15/0/15/30/45/60°。所有飞针发射后沿固定方向直飞，完全移除追踪；撞实体/边界消失。一阶段共用同一发射机制。

孢子：共3轮，每轮10个随机方向弹幕，轮间隔2秒；每发0.5攻击力（当前5点），最长15秒。圆形体积扫掠墙体、斜面、空心平台上下两侧、交互物及场景碰撞Area，接触时按表面法线镜面反射，保持速度与入射/出射角；第二次碰撞后销毁，命中玩家或越过无实体的地图边界也会消失。先扫掠场景、再检测其前方玩家，避免穿墙误伤。纯背景贴图不参与物理碰撞。一阶段仍为8秒、七发/1.0倍率孢子、单轮十发/0.5倍率针弹及30/30/40远程池。

危险预警：旋刃每次冲撞前最后0.2秒、冲击0.2秒蓄势期，显示通用红光，冲撞开始即消失。保留细红线、中央小亮芒、淡光晕及96×96六帧源素材，按制作人本轮要求整体放大4倍（nearest）。独立资源`assets/effects/danger_warning_v1/`，通用组件`DangerWarning`支持独立播放或按进度驱动。

## 韧性及血条提示

一阶段韧性300、二阶段450，不随区域倍率改变。所有Boss的破韧时长统一为`1+韧性×0.01`秒，因此本Boss分别为4秒和5.5秒；显式`paralysis_seconds`可覆盖通用公式。准备/冷却期间可被削韧，施法保护维持原规则；瘫痪期间受到伤害增加30%，重复命中不重新计时。恢复时回满本阶段韧性、按当前模式立即起手。

已从制作人填写的`docs/gameplay/削韧值填写表.md`同步28项削韧值到`data/poise.json`；空白旧bow_01条目保留null。未以生命伤害推导或擅填数值。普通敌人仍100韧性。

破韧时血条剧烈震动一次并播放3帧裂纹出现过程，随后保持布满裂纹的状态；恢复时再次震动、播放3帧修复过程并恢复正常血条。透明覆盖层参照当前血条生成，生命填充与最后一击归零仍由实际HP驱动。资源`assets/ui/corrumpt_poise_v1/`，原生350×16统一画布，参数来自`ui.poise`。实机对照`docs/previews/corrumpt_poise_comparison.png`从上至下为正常、破韧、恢复中。

## 转阶段过场与虚空湮灭

一阶段生命归零后播放6帧绽开/短根枯萎，长触手逐渐枯暗消失。首尾直接使用已确认的一、二阶段母版，固定128×128画布，原生像素、nearest、共同色板。花体上升128px后停留2秒，全屏紫光完全不透明时才提交二阶段数据与花心位置。全程隐藏HUD、增加上下黑边、锁定玩家操作和菜单，摄像机追踪Boss；紫光散去恢复原摄像机目标、HUD与操作。不得提前发出击败事件。

二阶段生命归零后先移至场地中央，5秒内剧烈震动，黑洞半径从6px扩大至60px（10倍）。每0.5秒生成引力环并施加短暂弱吸引；玩家保持操作，接触黑洞每物理帧失去1生命，不受普通受击间隔影响，也不产生逐帧硬直。达到最大后停止引力和吸引，在完全不透明紫光内隐藏Boss及黑洞。紫光散去且玩家仍存活、且未在本次招式中死亡，才发送一次击败事件；失败不发奖励，重生后重置遭遇。

演出资源在`assets/PROCESSED/enemies/BOSS-CLAFFERT/sequence_v001/`，完整提示词、来源及重建方式保存在该目录。`CorrumptSequence`统一管理锁定、摄像机、遮屏、伤害与结束恢复；演出时长、移动、震动、引力强度均从`sequence`数值表读取。除明确指定的2秒停顿、10倍黑洞和逐帧伤害外，演出调试时长可继续调整。

## 玩家反馈与闪避

闪避从55px/0.1s改为82.5px/0.2s（412.5px/s），60Hz下12个动作帧，全程无敌；已有地面/空中闪避素材按延长后的动作时长播放，人物像素与尺寸不变。体力消耗与冷却不变。

实际失去生命≤生命上限5%：屏幕边缘发红0.05秒；超过5%：发红0.1秒并轻震1.5px。全额免伤不提示；格挡、减伤、护盾吸收后再计算，致死过量部分不算损失。参数见`data/combat_feedback.json`。

距离、速度、未指定的起手/收招、转场时间为初始调试值，集中在JSON中；命中倍率、1.5/0.2秒停顿、循环数和模式顺序按制作人要求实现。
